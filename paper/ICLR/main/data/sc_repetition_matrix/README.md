## 实验范围与目的

对既有 Llama-3.1-8B-Instruct × GSM8K SC 结果做只读离线分析，共 1,319 题、42,208 条路径，每题 32 条。包含全部 281 条带截断标记的路径，没有根据正确率筛选。未启动生成任务，未调用外部服务，未修改原始结果。

本实验观察同题路径中的连续文本重复，以及数字和运算符均相同的数值表达式重复。它不检验共享前缀是否安全，也不直接估计 PC 能省去多少 token。

## 矩阵如何阅读

2026-09-19 作者要求更新 `q75_tokens` 为整格着色。该图任意高亮片段接触某格即填满该格；若有多色，取原始覆盖比例最大的非灰颜色，平局取图例中靠前的颜色。图中填色面积不再代表精确 token 覆盖率。其他五张图仍使用下述格内精确边界规则；原始匹配、统计和 `examples.json` 不变。单图复现命令为 `python3 analysis/sc_repetition_matrix.py render --only q75_tokens`。`snapshot.json` 中脚本哈希记录的是统计运行时版本，之后的改动仅涉及渲染。

- 纵轴为同一道题的 32 条 SC 路径，按原始 window、branch 顺序排列，没有为了增强条纹而重排行。
- 横轴覆盖每条完整路径，从 0% 到 100%，均分为 32 个区间。每行的绝对 token 数可能不同，图注报告范围。
- 分词使用原 Llama tokenizer。去掉文本内的特殊 token 标记后重新分词，不计 prompt；因此这是可见生成文本的 token 位置分析，并非直接读取生成账单。
- `*_tokens` 中，同色对应完全相同的连续 token 序列，最短 8 tokens；不做近似匹配或传递聚类。每题最多展示 8 类片段，以“长度 × 当前未覆盖出现次数”贪心选择，重叠位置只分配一次。不同片段可以处于不同相对位置。
- 格子内保留真实 token 边界，可以出现多种颜色，没有把局部匹配扩张成整个格子匹配。`examples.json` 保存每格各颜色占比。
- **灰色仅表示未被当前展示的片段覆盖，不代表不存在重复。** 全量重复覆盖率使用所有满足条件的片段，与图中的 8 类高亮不同。
- `*_operations` 中，同色对应相同的数值表达式，规范空白、千位分隔符、小数格式和乘除符号，保留负号与操作数顺序；例如 `5000*2` 与 `2*5000` 不合并。题目 prompt 中已经直接出现的表达式排除。
- 算式矩阵只给表达式本身所占的 token 上色，不给整个所在句上色。颜色仅在各图内部有意义，不能跨图比较。

## 样例选择

在运行前确定按“排除 prompt 原样 n-gram 后的 exact-8 覆盖率”排序，取最接近第 25、50、75 百分位的题目，平局按 source_row。未按图形效果、正确答案或算式数挑选。

| 样例 | source_row | exact-8 覆盖率（排除 prompt 原样片段） | 单个重复算式最多出现于多少条路径 |
|---|---:|---:|---:|
| q25 | 909 | 82.37% | 31/32 |
| median | 657 | 89.26% | 18/32 |
| q75 | 1078 | 93.07% | 7/32 |

这三个样例按**文本重复率**选择，不是按计算重复率选择。q75 的算式识别较少，其中不少运算夹有单位或文字，例如 `10 toothpicks/week * 12 weeks`，当前保守规则不识别此类表达式。不能据此认为该题实际中间计算重复更少。

## 全量描述性结果

对每题计算覆盖 token 的并集占本题 32 条可见路径总 token 数的比例，再对题目宏平均。只要某连续片段在至少两条不同路径出现，就算跨路径重复；只在单条路径内部重复不计。以下比例包含参与匹配的两端，不是“扣掉第一份以后的冗余量”。

| 最短完全匹配长度 | 全部重复片段覆盖率 | 排除 prompt 原样 n-gram 后 |
|---|---:|---:|
| 8 tokens | 86.39% | 85.94% |
| 16 tokens | 66.71% | 66.67% |
| 32 tokens | 34.03% | 34.03% |

排除 prompt 原样片段只消除了精确复制，不能消除改写题目、通用格式和答案复述。数值说明同题 SC 路径中存在长连续片段的重复，不等价于相同比例的计算可以被省去。许多片段散布于中后段，甚至最终答案附近，并非从开头就一致的完整共享前缀。

数值表达式扫描结果如下。

- 35,788 / 42,208 条路径识别到至少一个数值表达式。
- 1,306 / 1,319 题（99.01%）识别到至少一种跨路径重复、且不直接出现在 prompt 中的数值表达式。
- 35,269 / 42,208 条路径包含上述重复表达式。
- 重复表达式本身覆盖的 token 比例，题目宏平均为 4.98%。这不包括围绕计算的文字解释。
- 对每题每种重复表达式只计每条路径一次，然后扣掉一条路径，合计 98,578 次额外跨路径出现。这是**表达式出现次数**，不是重复 token 数，更不是已验证可移除的计算次数。

中位数样例 gsm8k_0657 中，`2*5000` 出现在 18/32 条路径，`5000+10000`、`150000+180000` 各出现在 15/32 条路径。它们分别对应同一问题的燃油月成本、合计月成本和第一年总成本。可在 `examples.json` 中追溯每次出现的原文和字符位置。

## 验证与边界

- 分析与绘图命令均正常结束。17 项针对新匹配逻辑和既有前缀分析的单元测试通过。
- 检查了同一路径内部重复不计入跨路径、prompt 排除、重叠并集、移位后的相同颜色、格子边界的分数覆盖、负数操作数等。
- 样例中的每个高亮 token 片段均逐项与原始 token 序列核对；每格颜色比例之和为 1。
- 检查渲染后的矩阵。没有使用整格多数颜色去填补局部重复。
- 开发测试发现初版正则会丢失负号，已添加回归测试并修复；报告和最终数据使用修复后的全量重扫结果。不是仅在图中手工修改。
- 数值表达式提取是保守的规则方法，未覆盖一般符号推导、LaTeX 分式、带单位的表达式或纯文字推理；也未为全库逐条人工标注其精确率和召回率。识别结果应称“检测到的重复数值表达式”，不能称完整语义推理步骤。
- 相同表达式可能位于不同推理上下文，没有据此合并语义状态，也没有检查表达式后面等号右侧结果是否正确。
- 同一题内路径的共同题目约束、模板语句及相同答案仍会产生重复。不存在异题对照或生成干预，因此不能声称重复全部无用，也不能声称删除这些片段必然保持准确率。
- 本实验为单模型、单数据集、单生成 seed 的探索性描述分析，不报告显著性检验或总体泛化置信区间。状态为 ANALYZED，未声明独立复现验证。

统计解释检查覆盖 11/11 项。辛普森悖论、碰撞变量、基率忽略、均值回归和反向因果在当前无组间效应、无干预比较设计中不适用；生态谬误通过区分题目宏平均与个例控制；选择偏差和幸存者偏差通过全量纳入、明确截断计数和公开样例排序规则控制；多重搜寻和分析自由度通过报告 8/16/32 三档及探索性身份说明；因果误读通过禁止将覆盖率解释为节省率明确限制。这不构成对其他模型或真实计算冗余的验证。

沿用 SC `q75_tokens` 的 8 种片段及原颜色，不在 PC 中重新聚类或选择片段。较深灰色 `#a6adb7` 表示实际复用的前缀，浅灰色 `#eceff3` 表示未被指定片段高亮的新生成内容。同色匹配后用前缀掩码覆盖，前缀灰色优先于其他颜色。任何与复用前缀相交的格子整格填灰，因此边界会向右扩张不足一个格子的距离；不能用灰色面积精确计算复用 token 数。其他格子沿用 SC 的整格规则。
